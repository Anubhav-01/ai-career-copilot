# API Reference

Interactive OpenAPI docs are auto-generated by FastAPI at **`/docs`**
(Swagger UI) and **`/openapi.json`**.

Base URL: `http://localhost:8000`. All endpoints below are prefixed with
`/api` and, unless noted, require `Authorization: Bearer <access_token>`.

## Conventions

- Errors: `{ "code": string, "message": string, "request_id": string }` with
  appropriate HTTP status (401/403/404/409/422/429/500/503).
- IDs are UUIDs. Timestamps are ISO-8601 UTC.
- Rate limit: 120 requests/min per client IP (429 beyond).

## Auth (public)

| Method | Path | Description |
|---|---|---|
| POST | `/auth/register` | Create account → token pair (201) |
| POST | `/auth/login` | Login → token pair |
| POST | `/auth/refresh` | Rotate refresh token → new pair |
| POST | `/auth/logout` | Revoke a refresh token |

## Auth (protected)

| Method | Path | Description |
|---|---|---|
| GET | `/auth/me` | Current user |
| POST | `/auth/change-password` | Change password (revokes all sessions) |
| POST | `/auth/delete-account` | Delete account + all data (password confirm) |

## Profile

| Method | Path | Description |
|---|---|---|
| GET | `/profile` | Get career profile |
| PUT | `/profile` | Update headline, location, experience years, target roles, links |

## Resumes

| Method | Path | Description |
|---|---|---|
| POST | `/resumes/upload` | Multipart upload (PDF/DOCX ≤5MB) → 202, background parsing |
| GET | `/resumes` | List own resumes with processing status |
| GET | `/resumes/{id}` | Detail: parsed extraction, skills + evidence, sections |
| DELETE | `/resumes/{id}` | Soft delete + remove stored file |
| POST | `/resumes/{id}/analyze` | Run scored analysis (components, ATS findings, recommendations, explanation) |
| GET | `/resumes/{id}/analysis` | Latest analysis (or null) |
| POST | `/resumes/{id}/improve-bullet` | Rewrite a bullet (must exist verbatim in resume) |
| POST | `/resumes/{id}/tailor/{job_id}` | Job-specific tailoring suggestions |

## Jobs & matching

| Method | Path | Description |
|---|---|---|
| POST | `/jobs/analyze` | Analyze pasted JD (≥100 chars) → stored job + extraction (201) |
| GET | `/jobs` | List analyzed jobs |
| GET | `/jobs/{id}` | Detail incl. full analysis |
| DELETE | `/jobs/{id}` | Soft delete |
| POST | `/jobs/{id}/match` | Body `{resume_id}` → hybrid match with components, strong/partial/missing skills, evidence, explanation |
| GET | `/jobs/{id}/match/{resume_id}` | Latest stored match for the pair |

## Skills, gaps & learning

| Method | Path | Description |
|---|---|---|
| GET | `/skills` | Unique skills across own resumes (with evidence) |
| POST | `/skills/gaps/{resume_id}/{job_id}` | Compute gaps (critical/important/nice_to_have) |
| GET | `/skills/gaps` | List all gaps |
| POST | `/learning/roadmaps/{gap_id}` | Generate roadmap for a gap (201) |
| GET | `/learning/roadmaps` | List roadmaps |

## Interviews

| Method | Path | Description |
|---|---|---|
| POST | `/interviews` | Create with target role, optional resume/job, difficulty, count → grounded questions (201) |
| GET | `/interviews` | List own interviews |
| GET | `/interviews/{id}` | Detail with questions (incl. answered flags) |
| POST | `/interviews/{id}/answer` | Body `{question_id, answer}` → feedback + next question + completion flag |
| GET | `/interviews/{id}/report` | Aggregated report |

## Applications

| Method | Path | Description |
|---|---|---|

## Dashboard & admin

| Method | Path | Description |
|---|---|---|
| GET | `/dashboard` | Per-user aggregates (cached): scores, skills, gaps, funnel, charts data |
